## 1. Ringkasan Penggunaan AI

Selama pengembangan proyek **KostHub**, AI digunakan sebagai **asisten pengembangan** untuk mempercepat proses coding, debugging, dan dokumentasi. Penggunaan AI dilakukan secara **kolaboratif** — saya tetap bertanggung jawab atas setiap keputusan arsitektural, desain, dan kualitas kode yang dihasilkan.

### Tools AI yang Digunakan

Semua interaksi AI dilakukan melalui **Antigravity** (VS Code Extension — Advanced Agentic Coding Assistant). Antigravity mendukung beberapa model AI yang bisa dipilih sesuai kebutuhan:

| Model | Platform | Kegunaan Utama |
|-------|----------|---------------|
| **Claude 4.6 Opus (Thinking)** | Antigravity (VS Code) | Deep debugging, root cause analysis, arsitektur kompleks |
| **Claude 4.6 Sonnet (Thinking)** | Antigravity (VS Code) | Code scaffolding, implementasi fitur, dokumentasi |
| **Gemini 3.1 Pro** | Antigravity (VS Code) | Quick fixes, troubleshooting, git operations |

> **Catatan:** Antigravity bukan sekadar chat AI — ia adalah agen otonom yang bisa menelusuri workspace, membaca/menulis file, menjalankan command terminal, mengoperasikan browser, dan melakukan git operations secara langsung di dalam project.

### LOG-06: Optimasi Performa & Fix Overview Mitra Dashboard

| Item | Detail |
|------|--------|
| **Tanggal** | 29 Juni 2026 |
| **AI Tool** | Antigravity (Claude 4.6 Opus → Gemini 3.1 Pro) |
| **Tujuan** | Fix overview yang tidak menampilkan pesanan terbaru, optimasi loading Finance & Orders |

**Konteks:**  
(1) Overview hanya menampilkan pesanan dengan status 'pending' — setelah user bayar, pesanan hilang. (2) Loading lama di halaman Finance dan Orders karena API call sequential dan re-render loop.

**Prompt Utama:**  
> "Kamu adalah seorang Senior Software Engineer yang akan melakukan debugging dan perbaikan bug pada aplikasi kami. Ikuti seluruh langkah di bawah ini secara berurutan — JANGAN melompat langsung ke coding sebelum menyelesaikan langkah 1 (pemahaman codebase)."

**Apa yang AI Bantu:**
- **Architecture Analysis**: Memetakan seluruh alur data Mitra Dashboard (endpoint → service → model → frontend state)
- **Bug #1 Root Cause**: `MitraDashboard.jsx` line 46 hardcode `{ status: 'pending' }` → pesanan hilang setelah pembayaran
- **Bug #1 Fix**: Ganti filter menjadi `{ limit: 5 }` (semua status) + refetch saat kembali ke tab overview
- **Bug #2 Root Cause**: Finance memiliki 2 API call sequential + debounce 300ms; Orders memiliki `useCallback` chain yang tidak stabil
- **Bug #2 Fix**: Parallelize API calls dengan `Promise.allSettled`, stabilkan `useCallback` deps dengan `useRef`
- **Bug #3 (Tambahan)**: Saldo di Overview mengambil data weekly (Rp 75.000) vs Finance all-time (Rp 4.000.000) → sinkronisasi endpoint

**Keputusan yang Saya Buat Sendiri:**
- Membuat fix branch terpisah (`fix/mitra-overview-and-performance`) dari `dev`
- Menyetujui untuk membuat PR terpisah dari bug fixes sebelumnya

**File yang Diubah:**
- `MitraDashboard.jsx` — Hapus filter `status: 'pending'`, tambah refetch, sinkronisasi saldo
- `MitraFinance.jsx` — Parallelize API calls, fix debounce
- `MitraOrders.jsx` — Stabilkan `useCallback` chain, cegah re-render loop

**Commit Terkait:**
- `3752441` — `fix(overview): show recent orders from all statuses instead of only pending`
- `b50c837` — `perf(finance,orders): parallelize API calls and fix re-render loops`

## 4. Refleksi & Etika Penggunaan AI

### Prinsip Penggunaan AI

1. **AI sebagai Akselerator, Bukan Pengganti**  
   AI digunakan untuk mempercepat scaffolding kode, debugging, dan penulisan dokumentasi. Semua keputusan arsitektural, desain UI, dan strategi pengembangan tetap saya tentukan sendiri.

2. **Validasi Output AI**  
   Setiap kode yang dihasilkan AI selalu saya review, test, dan modifikasi sebelum di-commit.

3. **Transparansi**  
   Penggunaan AI didokumentasikan dengan jelas dalam log ini. Prompt, konteks, dan keputusan yang dibuat dicatat untuk akuntabilitas.

4. **Pemahaman Mendalam**  
   Saya tidak hanya menerima output AI mentah — saya memahami *mengapa* sebuah solusi bekerja. Contoh: memahami root cause PgBouncer crash (prepared statements incompatibility) sebelum menerapkan fix.

### Apa yang AI Lakukan dengan Baik

- **Debugging kompleks**: AI sangat membantu dalam menemukan root cause bug yang melibatkan interaksi multi-layer (frontend → backend → database)
- **Code scaffolding**: Mempercepat pembuatan komponen React dan CSS boilerplate
- **Dokumentasi**: Membantu menyusun README, CHANGELOG yang konsisten

### Apa yang Tetap Memerlukan Keputusan Manusia

- **Arsitektur sistem** (monorepo vs polyrepo, auth strategy, state management)
- **Desain UI/UX** (color scheme, layout, user flow)
- **Prioritas fitur** (MVP scope, apa yang di-cut dari scope)
- **Code review** (menolak saran AI yang tidak sesuai konteks)
- **Trade-off teknis** (performance vs simplicity, consistency vs velocity)

## 5. Teknologi AI & Agen yang Digunakan

Dalam penyelesaian proyek ini, saya menggunakan platform **Antigravity** (Advanced Agentic Coding Assistant) yang terintegrasi langsung di VS Code. Antigravity mendukung beberapa model LLM yang bisa dipilih sesuai kebutuhan:

1. **Claude 4.6 Opus (Thinking)**  
   Model terkuat yang digunakan untuk tugas debugging kompleks dan root cause analysis multi-layer (frontend → backend → database). Digunakan secara intensif pada LOG-05 dan LOG-06 karena membutuhkan pemahaman arsitektur mendalam dan konteks panjang lintas banyak file.

2. **Claude 4.6 Sonnet (Thinking)**  
   Model yang seimbang antara kecepatan dan kualitas. Digunakan untuk implementasi fitur baru (scaffolding komponen React, halaman dashboard, service pages) dan penulisan dokumentasi proyek.

3. **Gemini 3.1 Pro**  
   Model cepat yang efektif untuk troubleshooting kilat, quick fixes, dan operasi git. Digunakan sebagai pelengkap pada beberapa sesi debugging, khususnya untuk penanganan error routing dan konfigurasi.

> **Penting:** Antigravity bukan sekadar chat AI — ia adalah agen otonom (*agentic*) yang mampu menelusuri seluruh workspace, membaca dan menulis file secara langsung, menjalankan perintah terminal, mengoperasikan browser untuk testing, serta melakukan operasi Git (commit, push, branch management) — semuanya langsung dari dalam lingkungan pengembangan.
