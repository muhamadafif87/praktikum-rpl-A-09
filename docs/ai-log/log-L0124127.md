# Log Penggunaan AI (AI Log) & Refleksi Evaluasi

**Nama Proyek:** KostHub / Praktikum Rekayasa Perangkat Lunak
**Peran:** Asisten Pengembang Aplikasi (Android & Web)

Dokumen ini berisi log detail mengenai interaksi dan penggunaan asisten AI dalam membantu proses pengembangan, _debugging_, arsitektur kode, serta penyelesaian masalah teknis pada tugas proyek ini. Dokumen ini juga memuat refleksi evaluatif mengenai efektivitas pemanfaatan AI.

---

## A. Log Detail Interaksi AI

### 1. Perbaikan Autentikasi Login dan Keamanan (Error HTTP 401)

- **Konteks:** Terdapat kendala saat pengguna melakukan login di aplikasi Android, di mana server mengembalikan status HTTP 401 Unauthorized padahal kredensial yang dimasukkan sudah benar.
- **Prompt / Pertanyaan:** "Bantu saya mencari tahu penyebab error 401 Unauthorized saat login dan bagaimana cara memperbaikinya di backend maupun frontend Android."
- **Solusi dari AI:** AI menganalisis alur kode dan menemukan adanya masalah _double-password hashing_ akibat _model casting_ yang salah. AI juga menyoroti perlunya perbaikan pada pengecekan tipe akun untuk mitra.
- **Tindakan Lanjutan:** Saya mengimplementasikan saran dari AI dengan memperbaiki logika _hashing_ pada _backend_, menyesuaikan model _AuthModels.kt_, dan memastikan _response token_ dapat dikelola dengan benar oleh sistem.

### 2. Perbaikan UI dan Navigasi Profil Pengguna (Android)

- **Konteks:** Tampilan avatar profil di halaman Home aplikasi Android masih berupa teks _hardcoded_ statis dan terdapat _bug_ pada navigasi (_backstack_) ketika pengguna melakukan _logout_.
- **Prompt / Pertanyaan:** "Bagaimana cara membuat efek _loading skeleton_ untuk avatar profil di Jetpack Compose, dan cara me-reset _navigation backstack_ ke layar login setelah berhasil _logout_?"
- **Solusi dari AI:** AI memberikan panduan _best practice_ penggunaan efek animasi _shimmer/skeleton_ pada Jetpack Compose. AI juga membagikan skrip perbaikan logika `navController` (menggunakan `popUpTo`) untuk mereset tumpukan layar.
- **Tindakan Lanjutan:** Saya memodifikasi komponen `ProfileAvatar.kt` dengan _loading skeleton_ dan membenahi alur di `HomeScreen.kt` ke layar autentikasi agar transisinya lebih mulus dan tidak meninggalkan sisa sesi memori.

### 3. Penyesuaian Method API pada Fitur Pesanan (Web)

- **Konteks:** Terdapat pesan error HTTP 405 "GET method not supported" saat aplikasi Web React mencoba mengambil detail data pesanan (Gas Galon, Laundry, Cleaning).
- **Prompt / Pertanyaan:** "Kenapa muncul error method GET not supported saat mengambil data detail pesanan, dan bagaimana rute Axios yang benar untuk menyelesaikannya?"
- **Solusi dari AI:** AI mengidentifikasi bahwa terdapat ketidaksesuaian (_mismatch_) antara definisi _router_ di _backend_ yang menggunakan POST, sedangkan pemanggilan di _frontend_ masih menggunakan GET. AI menyarankan perubahan method menjadi `api.post()`.
- **Tindakan Lanjutan:** Saya memperbarui kode HTTP _request_ di antarmuka Web sesuai petunjuk AI dan menyesuaikan struktur _payload body_ (JSON) yang dikirimkan.

### 4. Pembaruan Komponen Dashboard Mitra (Web)

- **Konteks:** Komponen UI dalam Dashboard Mitra (seperti menu Chat, Bantuan, Ulasan, dan Pengaturan) masih menggunakan data profil pengguna tiruan (_dummy_).
- **Prompt / Pertanyaan:** "Tolong bantu saya merombak _file_ Dashboard Mitra agar data profil (nama, foto) bersifat dinamis mengikuti sesi user saat ini ke semua _child component_."
- **Solusi dari AI:** AI membantu merancang ulang sistem operan data dengan memanfaatkan _Context API/Props_ untuk mendistribusikan _state_ _user_ secara merata ke setiap _sub-page_. AI juga memberikan desain struktur _dropdown_ profil yang rapi.
- **Tindakan Lanjutan:** Saya menyinkronkan _state_ login ke seluruh elemen Dashboard Mitra, menjadikan _user experience_ (UX) jauh lebih utuh dan sesuai data dari server.

### 5. Integrasi Remote API Client dengan Retrofit (Android)

- **Konteks:** Aplikasi membutuhkan sebuah arsitektur jaringan (_Network Call_) yang bersih dan terpusat untuk menghubungkan Android dengan backend API, terutama terkait pengaturan token otorisasi.
- **Prompt / Pertanyaan:** "Bagaimana cara mengatur kode pada `RetrofitClient.kt` yang efisien, mudah di-_maintain_, dan mendukung penyisipan Bearer Token secara otomatis di setiap _request_?"
- **Solusi dari AI:** AI memberikan rancangan instansiasi Retrofit yang berpadu dengan `OkHttpClient` beserta implementasi `Interceptor`. AI menunjukkan skrip agar token otomatis ditambahkan ke dalam _header_ "Authorization".
- **Tindakan Lanjutan:** Saya menerapkan arsitektur jaringan berbasis `RetrofitClient.kt` dan menghubungkannya dengan fungsi pengambil _token_ di sistem _cache_ aplikasi.

### 6. Pengembangan Antarmuka Halaman Admin Partner (Web)

- **Konteks:** Aplikasi membutuhkan halaman antar-muka (_dashboard_) bagi Admin untuk dapat mengelola, melihat, dan memvalidasi status mitra yang baru mendaftar.
- **Prompt / Pertanyaan:** "Buatkan struktur awal (_boilerplate_) komponen tabel di React untuk `AdminPartner.jsx` yang bisa menampilkan data, memiliki fungsi pencarian, dan tombol validasi (Setuju/Tolak)."
- **Solusi dari AI:** AI menghasilkan komponen fungsional yang sudah mencakup pembuatan tabel responsif, logika dasar _filtering_ data, serta kerangka fungsi _handler_ klik tombol admin.
- **Tindakan Lanjutan:** Saya mengadaptasi struktur UI dari AI tersebut, memperbaiki tata ruang/CSS agar selaras dengan panduan desain aplikasi, lalu mengaitkan _event handler_-nya ke _endpoint_ API aktual.

## B. Refleksi tentang Efektivitas Penggunaan AI

Penggunaan _Artificial Intelligence_ (AI) selama pengerjaan proyek KostHub memberikan dampak yang amat konstruktif, baik dari sisi efisiensi waktu maupun kualitas pengembangan perangkat lunak. Berikut adalah penjabaran refleksi mendalam tentang keefektifan penggunaan AI pada proyek ini:

1. **Akselerasi Proses _Debugging_ dan _Troubleshooting_**
   Salah satu kegunaan paling terasa dari AI adalah kecepatannya dalam menganalisis _stack trace error_ dan kode _buggy_ (seperti kendala _HTTP 401_ dan miskonfigurasi rute API). AI berperan layaknya instruktur pembantu atau _pair programmer_ virtual yang cakap memberikan titik terang saat pemikiran saya sedang buntu, mengubah durasi _debugging_ dari yang semula memakan waktu berjam-jam menjadi jauh lebih singkat.

2. **Pembelajaran Praktik Terbaik (_Best Practices_) dan Pematangan Arsitektur**
   AI terbukti sangat baik, tidak sekadar menyajikan kode mentah, namun ia juga menyertakan penalaran arsitekturalnya. Sebagai contoh: saat merancang `RetrofitClient` dengan Interceptor dan implementasi _navigation backstack_ Jetpack Compose. AI mengarahkan saya menggunakan standar desain industri yang tepat, sehingga memperkaya wawasan konseptual _software engineering_ saya.

3. **Meningkatkan Produktivitas dan Mengurangi Kode Repetitif**
   Dalam pengerjaan tugas rutin yang bersifat _repetitive_ dan minim variasi—seperti pembuatan antarmuka tabel (`AdminPartner.jsx`), _loading skeleton_, atau penulisan _boilerplate_ data model—AI sukses membantu membangun kerangka awalnya dengan instan. Karena bagian dasar yang melelahkan sudah ditangani AI, saya dapat lebih berfokus pada pekerjaan logis yang rumit, penyesuaian estetika desain, serta penanganan alur bisnis utama (_core logic_).

4. **Menekankan Perlunya Kajian Kritis (Peran Manusia Tidak Tergantikan)**
   Di sisi lain, interaksi intensif dengan AI menumbuhkan sikap pemahaman kritis. Terkadang AI dapat memberikan saran pustaka (_library_) versi usang atau menawarkan asumsi struktur kode yang meleset dari konteks repositori proyek secara menyeluruh (_hallucination_). Hal ini mengajarkan refleksi krusial: peran _developer_ (manusia) mutlak diperlukan sebagai sang evaluator. Setiap solusi maupun sintaks dari AI senantiasa saya teliti ulang, uji reliabilitasnya, kemudian dimodifikasi (_refactor_) secara cermat agar kompatibel seutuhnya dengan ekosistem KostHub.

**Kesimpulan**
Secara menyeluruh, pemanfaatan asisten AI telah sukses bertransformasi dari sekadar mesin pencari pintar menjadi mitra kolaborasi yang efektif. Asalkan diawaki dengan panduan masukan (_prompt_) yang spesifik serta pengawasan teknis ketat oleh pengembang (verifikasi manusia), AI secara faktual berhasil mendongkrak laju penyelesaian proyek dan mendewasakan tingkat kecakapan _problem-solving_ saya selaku perancang aplikasi perangkat lunak.

## C. Teknologi AI & Agen yang Digunakan

Dalam penyelesaian tugas dan operasional proyek ini, saya mensinergikan beberapa alat pendukung pemodelan bahasa canggih (LLM) serta asisten kode otonom, yaitu:

1. **Claude 4.6 Sonnet**  
   Model ini digunakan secara intensif untuk perancangan hierarki struktur antarmuka UI/UX (terutama pada React), menganalisa *bug* pada arsitektur berantai, dan penulisan skrip-skrip logika *frontend* yang membutuhkan jendela konteks panjang dan pemahaman relasional kode yang rumit.

2. **Gemini Pro**  
   Berperan dominan dalam menangani analisis *backend*, *troubleshooting* kilat, dan pencarian solusi presisi seperti penanganan *error routing* (HTTP status code). Model ini sanggup merunut akar persoalan pada level sintaksis dasar dengan sangat cepat dan memberikan panduan *best-practice* berstandar tinggi.

3. **Antigravity**  
   Alat ini merupakan agen *Advanced Agentic Coding Assistant* (diaktifkan melalui lingkungan sistem terintegrasi). Alih-alih hanya berbalas *chat*, agen otonom Antigravity bertindak layaknya *pair programmer* harafiah yang bisa menelusuri ruang kerja (*workspace*) saya, meriset ratusan *file*, mengeksekusi operasi manajemen Git (seperti membaca status dan resolusi konflik), hingga melakukan otomatisasi pengeditan (*auto-editing*) struktur fail secara langsung pada basis kode proyek secara presisi.
