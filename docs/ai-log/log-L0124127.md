## 1. Ringkasan Penggunaan AI

Selama pengembangan proyek **KostHub**, AI digunakan sebagai **asisten pengembangan** untuk mempercepat proses coding, debugging, dan penyusunan arsitektur sistem. Penggunaan AI dilakukan secara **kolaboratif** — saya tetap bertanggung jawab atas setiap keputusan arsitektural, logika keamanan, dan kualitas kode yang dihasilkan.

### Tools AI yang Digunakan

Semua interaksi AI dilakukan melalui **Antigravity** (VS Code Extension — Advanced Agentic Coding Assistant). Antigravity mendukung beberapa model AI yang bisa dipilih sesuai kebutuhan:

| Model                            | Platform              | Kegunaan Utama                                                               |
| -------------------------------- | --------------------- | ---------------------------------------------------------------------------- |
| **Claude 4.6 Sonnet (Thinking)** | Antigravity (VS Code) | Penulisan scaffolding komponen UI, integrasi React, dan arsitektur Retrofit. |
| **Gemini 3.1 Pro**               | Antigravity (VS Code) | Quick fixes, troubleshooting kilat HTTP error, dan analisa backend.          |

> **Catatan:** Antigravity bukan sekadar chat AI — ia adalah agen otonom yang bisa menelusuri workspace, membaca/menulis file, menjalankan command terminal, mengoperasikan browser, dan melakukan git operations secara langsung di dalam project.

### LOG-01: Perbaikan Autentikasi Login (Error HTTP 401)

| Item        | Detail                                                                                |
| ----------- | ------------------------------------------------------------------------------------- |
| **Tanggal** | Juni - Juli 2026                                                                      |
| **AI Tool** | Antigravity (Gemini 3.1 Pro)                                                          |
| **Tujuan**  | Mencari penyebab dan memperbaiki error 401 Unauthorized saat proses login di Android. |

**Konteks:**  
Terdapat kendala saat pengguna melakukan login di aplikasi Android, di mana server mengembalikan status HTTP 401 padahal kredensial yang di-input sudah benar.

**Prompt Utama:**

> "Bantu saya mencari tahu penyebab error 401 Unauthorized saat login dan bagaimana cara memperbaikinya di backend maupun frontend Android."

**Apa yang AI Bantu:**

- Menganalisis alur kode dan menemukan adanya masalah _double-password hashing_ akibat _model casting_ yang salah.
- Menyoroti perlunya perbaikan pada pengecekan tipe akun untuk autentikasi level mitra.

**Keputusan yang Saya Buat Sendiri:**

- Memperbaiki logika hashing di _backend_ agar tidak menimpa hash yang sudah ada.
- Menyesuaikan model data `AuthModels.kt` dan memastikan pengelolaan response token tersimpan dengan aman di sistem tanpa cacat arsitektur.

### LOG-03: Penyesuaian Method API pada Fitur Pesanan (Web)

| Item        | Detail                                                                              |
| ----------- | ----------------------------------------------------------------------------------- |
| **Tanggal** | Juni - Juli 2026                                                                    |
| **AI Tool** | Antigravity (Gemini 3.1 Pro)                                                        |
| **Tujuan**  | Memperbaiki error HTTP 405 "GET method not supported" pada _fetching_ data pesanan. |

**Konteks:**  
Gagal memuat halaman Gas Galon, Laundry, Cleaning di React akibat method HTTP yang tidak sinkron antara pemanggilan Axios dan _routing_ di Laravel.

**Prompt Utama:**

> "Kenapa muncul error method GET not supported saat mengambil data detail pesanan, dan bagaimana rute Axios yang benar untuk menyelesaikannya?"

**Apa yang AI Bantu:**

- Mengidentifikasi bahwa _router_ backend mendefinisikan rute POST sementara frontend salah memanggil GET.
- Menyediakan sintaks perbaikan untuk _request_ Axios menjadi `api.post()`.

**Keputusan yang Saya Buat Sendiri:**

- Menyelaraskan struktur _payload body_ (JSON) yang dikirimkan.
- Memastikan token autorisasi (Bearer) tetap tersemat dengan aman saat mengubah jenis method _request_.

## 4. Refleksi & Etika Penggunaan AI

### Prinsip Penggunaan AI

1. **AI sebagai Akselerator, Bukan Pengganti**  
   AI saya posisikan mutlak untuk mempercepat pembuatan _boilerplate_ antarmuka dan proses _debugging_ _error log_. Kendali atas tata letak utama, keputusan arsitektur (seperti _Singleton Pattern_), serta jaminan mutu keamanan sepenuhnya berada di tangan saya.

2. **Validasi Output AI (Human-in-the-loop)**  
   Semua segmen _UI component_ maupun logika API yang disarankan AI tidak langsung ditelan mentah-mentah ke _production_. Setiap sintaks saya _review_, modifikasi (_refactor_), dan asimilasikan ke tatanan desain proyek yang sudah ada.

3. **Transparansi Interaksi**  
   Saya mencatat alur riwayat instruksi spesifik (_prompting_) yang saya berikan kepada agen AI untuk memilah batas tegas antara karya mesin dan kontribusi saya pribadi sebagai penanggung jawab proyek.

### Apa yang AI Lakukan dengan Baik

- **Mendeteksi Root Cause**: Kemampuan AI mendeteksi letak detail _bug_ (seperti _mismatch routing_ dan hash _password_) menghemat berjam-jam waktu investigasi.
- **Penyusunan Boilerplate Cepat**: Sangat luar biasa responsif dalam membangkitkan struktur tabel data (React) maupun implementasi kompleks jaringan _Network Client_ (Android).

### Apa yang Tetap Memerlukan Keputusan Manusia

- **Manajemen State Khusus Aplikasi**: Menentukan secara mandiri pola relasi status lintas komponen yang paling aman dan koheren untuk ekosistem KostHub.
- **Penyelarasan Desain (_Styling System_)**: Menyisir ulasan AI agar estetika (warna, tata letak, hirarki visual) tetap tunduk pada panduan identitas sistem proyek.
- **Pengawasan Kelayakan Mutu**: Mencekal anjuran _hallucination_ AI (misalnya menyisipkan paket _library_ usang) dengan melakukan verifikasi fungsionalitas secara terus-menerus.

## 5. Teknologi AI & Agen yang Digunakan

Dalam penyelesaian proyek ini, saya menggunakan platform **Antigravity** (Advanced Agentic Coding Assistant) yang terintegrasi langsung di IDE VS Code. Antigravity mendukung beberapa model LLM termutakhir, yakni:

1. **Claude 4.6 Sonnet**  
   Model andalan saya untuk skenario pengembangan kompleks karena kecepatannya. Saya manfaatkan dominan untuk penyusunan komponen UI/UX _frontend_, merancang _state management_, serta menyusun _boilerplate_ API Android (_Retrofit_). Sangat diandalkan pada penulisan struktur berbasis komponen dan pemahaman hierarki file berantai.

2. **Gemini 3.1 Pro**  
   Model lincah yang saya turunkan ketika butuh resolusi sekejap mata untuk mengurai _error log_. Utamanya digunakan dalam skenario _troubleshooting_ insiden spesifik, membongkar mis-konfigurasi _routing HTTP_, serta analisa silang interkoneksi backend ke _mobile_.

3. **Antigravity (Agen Otonom)**  
   Lebih dari sekadar obrolan _chatbot_, saya menugaskan agen **Antigravity** bertindak seperti _pair-programmer_ nyata. Asisten ini menyisir seluruh proyek tanpa lelah, membaca berbagai kode di puluhan berkas yang berbeda secara otomatis, menulis kode yang telah dirapikan (auto-editing), hingga membantu memecahkan dan melakukan _commit_ resolusi konflik Git secara utuh di ranah pengembangan lokal.
