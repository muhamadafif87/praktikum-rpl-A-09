## AI Governance Statement

Selama pengembangan backend KostHub, AI digunakan sebagai **engineering copilot** untuk meningkatkan produktivitas pada aktivitas implementasi, dokumentasi teknis, debugging, dan refactoring.

AI **tidak digunakan sebagai pengambil keputusan sistem**. Seluruh keputusan mengenai:

* software architecture,
* database design,
* business rules,
* API contract,
* security implementation,
* deployment,
* code review,

Seluruh kode yang dihasilkan AI melalui proses:

1. Requirement decomposition
2. Prompt orchestration
3. Human review
4. Manual modification
5. Static analysis
6. Local testing
7. Integration testing
8. Final approval sebelum merge ke repository.

# Prompt Engineering Strategy

AI digunakan melalui pendekatan **task-oriented prompt orchestration**, di mana setiap pekerjaan backend dipecah menjadi beberapa sub-task kecil agar keluaran AI tetap terkontrol dan mudah divalidasi.

Tahapan orkestrasi meliputi:

1. Analisis kebutuhan fungsional dan nonfungsional.
2. Dekomposisi pekerjaan menjadi task independen (misalnya autentikasi, validasi, service layer, atau endpoint CRUD).
3. Penyusunan prompt dengan konteks proyek, standar Laravel, batasan arsitektur, dan kebutuhan bisnis.
4. Evaluasi keluaran AI terhadap standar pengkodean, keamanan, dan konsistensi desain.
5. Refinement iteratif melalui beberapa siklus prompt hingga solusi memenuhi kebutuhan implementasi.
6. Integrasi hasil yang telah direvisi ke dalam basis kode melalui proses review dan pengujian.

Pendekatan ini memastikan AI berfungsi sebagai **alat bantu implementasi**, sementara kontrol teknis dan keputusan rekayasa tetap berada pada engineer.

# Compliance Statement

Penggunaan AI pada proyek KostHub mengikuti prinsip **human-in-the-loop**, di mana AI dimanfaatkan sebagai alat bantu produktivitas untuk menghasilkan draft implementasi, alternatif solusi, dokumentasi, dan analisis teknis. Seluruh keputusan arsitektur, implementasi logika bisnis, konfigurasi keamanan, serta proses validasi tetap berada di bawah tanggung jawab engineer.

Sekitar **30% implementasi backend** memperoleh bantuan AI pada tahap penyusunan kode awal, refactoring, debugging, dan dokumentasi. Sebelum diintegrasikan ke repository, setiap hasil AI melalui proses orkestrasi tugas, review manual, modifikasi, pengujian unit, pengujian integrasi, dan verifikasi akhir sehingga memenuhi standar kualitas perangkat lunak dan dapat dipertanggungjawabkan secara teknis maupun audit.
